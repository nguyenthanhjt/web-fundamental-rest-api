# Course 6 - Assignment – Authentication & Authorization

Dựa trên source code của course 4, các bạn tiếp tục phát triển hệ thống với các yêu cầu sau:

- Bổ sung cơ chế Authentication và Authorization.
- Áp dụng cơ chế Stateless Authentication.
- Kiểm soát quyền truy cập vào các API và tài nguyên trong hệ thống.
- Đảm bảo các nguyên tắc bảo mật và REST API đã học.

Đây là bài tập mở, các bạn chủ động nghiên cứu, phân tích, thiết kế và lựa chọn giải pháp phù hợp.

Yêu cầu bàn giao: Tạo Pull Request (PR) để review, kèm theo một file tài liệu Markdown mô tả giải pháp, cơ chế hoạt động và lý do lựa chọn giải pháp đó.
